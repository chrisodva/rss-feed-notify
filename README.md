# rss-feed-notify
A Firefox extension that checks a list of RSS feeds on demand and marks the corresponding bookmark in a folder if there is new content since last visit. 

Normal Firefox blocks unsigned extensions. To use this you need either Firefox ESR or a nightly version.

Install the extension. Import feeds or add manually. Create bookmark folder named RSS Feeds that corresponds to the feeds. When you press check it will check the feed list and mark bookmarks with new content in the feed with a bold black dot. The dot goes away when you click through the bookmark to visit the site.
